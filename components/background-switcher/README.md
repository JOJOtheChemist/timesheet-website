# 背景切换器组件

## 功能描述
背景切换器是一个用于动态切换网页背景的组件，支持多种背景风格和自动切换功能。

## 文件结构
- `background-switcher.css` - 样式文件
- `background-switcher.js` - 功能脚本
- `README-背景切换器.md` - 详细说明文档

## 使用方法
1. 引入CSS文件：`<link rel="stylesheet" href="components/background-switcher/background-switcher.css">`
2. 引入JS文件：`<script src="components/background-switcher/background-switcher.js"></script>`

## 快捷键
- `Ctrl + 1` - 切换到背景1
- `Ctrl + 2` - 切换到背景2  
- `Ctrl + 3` - 切换到背景3
- `Ctrl + 4` - 切换到背景4

## 特性
- 自动背景切换
- 键盘快捷键支持
- 响应式设计
- 平滑过渡效果
