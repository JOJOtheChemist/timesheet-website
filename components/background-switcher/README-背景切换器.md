# 背景图切换器使用说明

## 功能特性

🎨 **智能背景切换**：根据时间自动选择合适的背景图
🔄 **滚动触发**：滚动 `schedule-table-container` 时自动切换背景
🎮 **手动控制**：右上角按钮组可手动切换背景
⌨️ **键盘快捷键**：Ctrl+1/2/3/4 快速切换
📱 **响应式设计**：支持移动端和桌面端

## 背景图类型

- 🌙 **夜间** (night.webp) - 默认背景
- 🌅 **早晨** (morning.webp) - 6:00-10:00
- ☀️ **白天** (day.webp) - 10:00-18:00  
- 🌆 **傍晚** (dusk.webp) - 18:00-20:00

## 使用方法

### 1. 自动切换
- 页面加载时根据当前时间自动选择背景
- **仅滚动日程表容器时自动切换背景**（页面整体滚动不影响背景）

### 2. 手动切换
- 点击右上角圆形按钮切换背景
- 按钮图标对应不同时间段

### 3. 键盘快捷键
- `Ctrl + 1` - 切换到夜间背景
- `Ctrl + 2` - 切换到早晨背景  
- `Ctrl + 3` - 切换到白天背景
- `Ctrl + 4` - 切换到傍晚背景

## 文件结构

```
timesheet/
├── daily_schedule.html          # 主HTML文件
├── background-switcher.css      # 背景切换器样式
├── background-switcher.js       # 背景切换器脚本
└── static/images/蕨类/          # 背景图片文件夹
    ├── night.webp              # 夜间背景
    ├── morning.webp            # 早晨背景
    ├── day.webp                # 白天背景
    └── dusk.webp               # 傍晚背景
```

## 技术实现

- **CSS**: 使用 `transition` 实现平滑的背景切换动画
- **JavaScript**: 基于类的背景切换系统
- **滚动检测**: **仅监听 `schedule-table-container` 的滚动事件**，页面整体滚动不影响背景
- **时间检测**: 根据当前小时自动选择合适背景

## 自定义配置

可以在 `background-switcher.js` 中修改：
- 背景图路径
- 切换动画时长
- 时间区间设置
- UI样式配置

## 注意事项

1. 确保背景图片路径正确
2. 背景图片建议使用 WebP 格式以获得更好的性能
3. 图片尺寸建议保持一致以获得最佳显示效果
